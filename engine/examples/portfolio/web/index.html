Both queries.

Independent process measurements and server history for the all-products query and the top-ten query. Sample ages and missing values stay explicit.
Process counters reset on worker restart. Latency distributions cover the preceding 60 seconds; browser delivery is excluded. Commit observers follow each query’s durable progress even if no result row changes. CPU and PUT-only request counts are not collected.
